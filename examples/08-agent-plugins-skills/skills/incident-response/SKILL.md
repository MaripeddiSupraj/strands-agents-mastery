# Incident Response

When investigating an incident:

1. Establish the symptom, service, environment, and time window.
2. Gather evidence before proposing a root cause.
3. Separate observed facts from hypotheses.
4. State what evidence is still missing.
5. Recommend the smallest useful next diagnostic step.
6. Never claim remediation occurred unless an authorized system confirms it.
